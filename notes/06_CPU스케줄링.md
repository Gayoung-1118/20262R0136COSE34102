# 6강 — CPU 스케줄링

## 핵심
- ready 상태 프로세스 중 하나를 골라 CPU를 주는 것
- 호출 시점: 타임 슬라이스 만료 / waiting 진입 / 종료
- 평가 기준: 이용률, 대기 시간, 반환 시간, 처리량, 응답 시간

## 알고리즘
| 알고리즘 | 특징 |
|---|---|
| FCFS | 단순, 호위 효과 |
| SJF | 평균 대기 시간 최적 (비선점) |
| SRTF | 선점형 SJF, 버스트를 알 수 없어 비현실적 |
| Priority | 기아 → **에이징**으로 해결 |
| RR | 응답성·공평성 vs 스위칭 오버헤드 |
| MLFQ | 큐 간 이동, 주기적 승격으로 기아 방지 |

## 기억할 것
- 도착 시간이 있으면 대기 시간은 도착 기준으로 계산
- 타임 슬라이스가 모든 버스트보다 크면 RR = FCFS
