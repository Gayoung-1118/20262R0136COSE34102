# 4강 — 컨테이너, 컴퓨터 시스템, 트랩과 인터럽트

## 컨테이너 vs VM
- 컨테이너: 호스트 커널 공유 → 가볍고 빠름 / 격리·보안 약함, 호스트 OS 의존
- 구현 ≈ 프로세스 + **cgroup**(자원 제한) + **namespace**(ID 격리)

## 트랩 vs 인터럽트
| | 트랩 | 인터럽트 |
|---|---|---|
| 종류 | 동기 | 비동기 |
| 원인 | 실행 중인 명령어 (시스템 콜, 예외) | 하드웨어 (타이머, NIC, I/O 완료) |
| 복귀 | 보통 같은 프로세스 | 원래 프로세스 또는 다른 프로세스 |

## 기억할 것
- 모드 스위치(권한만 변경) 비용 ≪ 컨텍스트 스위치(프로세스 교체)
- 타이머 인터럽트 덕분에 시분할이 가능
