# 3강 — OS 구조, 시스템 콜, 가상화

## 시스템 콜
- 유저 모드 → 커널 모드로 들어가는 **유일한 통로**
- `printf` → C 라이브러리 → `write()` → 모드 스위치(U→K) → 시스템 콜 테이블에서 핸들러 → 실행 → 복귀(K→U)
- 파라미터 전달: 레지스터 / 메모리 주소(메타데이터)를 레지스터로

## 커널 구조
| | 모놀리식 | 마이크로커널 |
|---|---|---|
| 구조 | 커널 전체가 한 프로그램 | 기능별 서버, 각자 주소 공간 |
| 기능 간 호출 | 함수 호출 | IPC (+컨텍스트 스위치) |
| 성능 | 좋음 | 나쁨 |
| 장애 | 전체 다운 | 해당 서버만 재시작 |

## 가상화
- 하이퍼바이저: 자원 분배 + 일루전(에뮬레이션)
- 오버헤드: 번역 + **스케줄링 2회**
- 해결: 반가상화(하이퍼콜), 하드웨어 지원(VT-x, AMD-V)
