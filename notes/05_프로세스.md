# 5강 — 프로세스

## 핵심
- 프로세스 = 실행 중인 프로그램, **자원 분배 단위 + 보호 도메인 단위**
- 메모리 4영역: text / data / heap(↑) / stack(↓)
- PCB: 프로세스당 1개, 커널 메모리, 리눅스는 `task_struct`

## 상태 전이
- new → ready ⇄ running → terminated
- running → waiting (블로킹 I/O) → ready (I/O 완료 인터럽트)
- 타이머 만료, `sched_yield()` → ready

## fork / exec / wait
- `fork()` 1번 호출 → 2번 리턴 (부모: 자식 PID, 자식: 0)
- PC까지 복사 → 둘 다 fork 다음 줄부터 실행
- fork n번 연속 → 프로세스 2ⁿ개
- `exec()`: 주소 공간을 새 프로그램으로 교체
- `wait()`: 부모가 자식 종료까지 대기
