# 7강 — IPC (프로세스 간 통신)

## 두 모델
| | 공유 메모리 | 메시지 전달 |
|---|---|---|
| 커널 개입 | 생성·매핑만 | 매 send/receive |
| 속도 | 빠름 | 느림 (복사·모드 스위치) |
| 동기화 | 사용자가 직접 | 커널이 처리 |

## 메시지 전달 예
- 시그널: 미리 정의된 이벤트 (SIGKILL은 막을 수 없음)
- 파이프: 단방향 1:1
- 메시지 큐: N:M
- 소켓: 다른 머신과도 통신 (IP + 포트)

## 기억할 것
- `count++`도 load → 연산 → store 3단계 → 경쟁 상태 → lock 필요
