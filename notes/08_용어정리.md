# 용어 정리

| 용어 | 뜻 |
|---|---|
| 커널 모드 / 유저 모드 | CPU의 특권 수준. 커널 모드에서만 특권 명령·커널 메모리 접근 가능 |
| 시스템 콜 | 유저 프로그램이 커널 서비스를 요청하는 통로 |
| 모드 스위치 | 같은 프로세스에서 CPU 특권 모드만 바뀌는 것 |
| 컨텍스트 스위치 | 실행 중인 프로세스를 다른 프로세스로 교체 (PCB 저장·복원) |
| PCB | 프로세스의 정보를 담은 커널 자료구조 (리눅스 `task_struct`) |
| 트랩 | 실행 중인 명령어가 일으키는 동기 이벤트 |
| 인터럽트 | 하드웨어가 일으키는 비동기 이벤트 |
| 선점 | OS가 실행 중인 프로세스에게서 CPU를 강제로 가져오는 것 |
| 기아 / 에이징 | 낮은 우선순위가 계속 밀리는 현상 / 기다릴수록 우선순위를 올려 해결 |
| 보호 도메인 | 다른 프로세스의 메모리에 접근할 수 없게 막는 단위 |
