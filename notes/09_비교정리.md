# 헷갈리는 개념 비교

## 모드 스위치 vs 컨텍스트 스위치
- 모드 스위치: CPU 권한만 바뀜, 비용 작음 (예: 시스템 콜)
- 컨텍스트 스위치: 실행 프로세스 자체가 바뀜, 비용 큼 (예: 타임 슬라이스 만료)

## 동기 I/O vs 비동기 I/O
- 동기: 결과가 나올 때까지 기다림 → 스풀링 불가
- 비동기: 요청만 하고 다음 일 진행

## VM vs 컨테이너
- VM: 게스트마다 커널, 격리 강함, 무거움
- 컨테이너: 호스트 커널 공유, 가볍움, 격리 약함

## 공유 메모리 vs 메시지 전달
- 공유 메모리: 빠름, 동기화는 사용자 책임
- 메시지 전달: 커널 경유, 안전하지만 느림
