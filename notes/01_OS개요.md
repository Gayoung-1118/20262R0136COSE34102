# 1강 — 운영체제 개요

## 핵심
- OS = 다양한 하드웨어와 앱 사이의 **인터페이스 계층**
- 두 역할: 요구사항(공평성·고성능·응답성)에 맞게 자원을 **할당**하고, 낭비 없이 **관리**
- OS = **추상화(Abstraction) + 정책(Policy) + 메커니즘(Mechanism)**
- 대표 추상화: **프로세스 · 주소 공간 · 파일 · 소켓**

## 기억할 것
- 정책 = "누구에게? 얼마나 오래? 중간에 멈출 것인가?"
- **항상 최고인 정책은 없다** → 시스템 목표에 맞춰 선택
- 메커니즘 시간 = 사용자가 못 쓰는 오버헤드 → 가볍게 구현해야 함
- 주소 공간 = **보호 도메인** → 프로세스 간 격리, 통신은 IPC로
- 이 수업에서 **OS == Kernel**
